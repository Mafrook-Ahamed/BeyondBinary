# Figma Design

Design file: https://www.figma.com/design/vc80nQ5oJS4vOMVpNLwXV6

## Initial screen

SOC Operations Dashboard / Command Center.

Included sections:
- Product identity and workspace navigation
- Overview metrics
- Priority attack queue with severity, category, affected count, confidence, first-seen time, and status
- Attack correlation panel
- Human decision recommendation with evidence summary

The numbers and incidents in the mockup are illustrative UI content only. They are not model results or live telemetry.
